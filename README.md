# Kraken — On-chain ETF distribution protocol

Landing page for **Kraken**, an on-chain protocol that distributes tokenized ETF
exposure directly to token holders.

- **Static site** — `index.html` + `styles.css` + `/assets`
- **Palette** — black / white / grey, cinematic
- **Visuals** — original AI-generated black & white oil-painting artwork (stormy sea & giant kraken)

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Deployed as a static site on Vercel.
